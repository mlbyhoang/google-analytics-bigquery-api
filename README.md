# Google Analytics & BigQuery API

## Overview

A collection of Python scripts and Jupyter Notebooks for working with the Google Analytics 4 (GA4) Data API and Google BigQuery.

This repository serves as a personal code portfolio and a central place for storing, organizing, and maintaining API integrations, data extraction workflows, and analytical queries.

## Contents

### Google Analytics 4 API

- Data extraction using the GA4 Data API

- Custom dimensions, metrics, and filters

- Pagination and API response processing

- Data transformation with Pandas

### Google BigQuery API

- BigQuery integration with Python

- SQL-based data extraction and filtering

- Query execution and result processing

- Integration with Pandas DataFrames

### Tech Stack

- Python

- Google Analytics Data API

- Google Cloud BigQuery

- SQL

- Pandas

- Jupyter Notebook / Google Colab
